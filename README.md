# Logpilot

Dashboard lokal untuk meninjau logbook magang.

## Jalankan dashboard awal

Dari folder proyek:

    cd frontend
    npm run dev

Buka http://localhost:3000. Rentang tanggal awal dibatasi pada 21 September 2026–20 Januari 2027. Data belum dibaca atau dikirim pada tahap ini.

DaisyUI digunakan untuk komponen antarmuka dan tema lokal. Lihat [komponen DaisyUI](https://daisyui.com/components/) dan [panduan instalasi Next.js](https://daisyui.com/docs/install/nextjs/).

Otomasi tidak akan menekan tombol penyelesaian logbook.
